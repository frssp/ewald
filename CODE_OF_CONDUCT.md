# Code of conduct

EWALD follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and welcoming, criticise ideas rather than people, and accept that
the maintainer may remove comments, commits, issues or other contributions that break these
rules, or ban someone from the project for doing so.

It applies in the repositories frssp/ewald and frssp/ewald-plugins (issues, pull requests,
discussions, reviews) and wherever someone represents the project in public.

## Reporting

Write to the maintainer, Sunghyun Kim, at <frssp.kim@gmail.com>. Reports are read in
confidence, and the person reporting is protected from retaliation. The maintainer decides on
the response following the Covenant's enforcement guidelines (correction, warning, temporary
ban, permanent ban).

Security vulnerabilities go through [SECURITY.md](SECURITY.md) instead.
