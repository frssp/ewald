# Examples

The example structure and trajectory files are installed with ewald as package data, so they are
available right after `pip install` without cloning the repository. In the repository they live in
[`src/ewald/examples/files/`](../src/ewald/examples/files/), generated by
`python -m ewald.examples.make_examples` (never edit them by hand).

| File | Format | Contents |
| --- | --- | --- |
| `POSCAR.SrTiO3` | VASP POSCAR | cubic perovskite SrTiO3, 2x2x2 (40 atoms) |
| `Si.cif` | CIF | diamond Si, conventional cell (8 atoms) |
| `Pt_nanoparticle.xyz` | XYZ | Pt truncated-octahedron nanoparticle (201 atoms), no cell |
| `Cu_md.extxyz` | extended XYZ | fcc Cu (108 atoms), 10 frames with forces and energy |
| `XDATCAR.Si` | VASP XDATCAR | diamond Si (64 atoms), 10-frame trajectory |
| `CHGCAR.Si` | VASP CHGCAR | diamond Si with a synthetic valence density |
| `Cu_void.lammpstrj` | LAMMPS dump | Cu block with a spherical void (462 atoms), 5 frames |
| `CuZr.data` | LAMMPS data | B2 CuZr (128 atoms), types named in Masses |

Trajectories, forces and the CHGCAR density are synthetic; they are meant for trying the viewer and
the modifiers, not as physical data.

## Where the data comes from

- The example files above are made by ewald's own generator; no outside data is in them.
- The tutorial notebooks in `notebooks/` use only those example files.
- The paper scripts in `papers/` download the authors' files on first use; ewald does not
  redistribute them. Each script's docstring names the repository, its license and the paper, and
  `docs/user/papers.md` lists every dataset with its citation, DOI and license
  (`ewald examples --papers` prints the same). Cite the original paper when you use its data.
- The only third-party files committed to the repository are the reader fixtures in
  `tests/data/real/` (pymatgen test files, MIT; one LAMMPS example log, GPL-2.0); their README
  gives the source commit and license notice of each.

## Opening them

In the GUI: **File › Open example**.

From the command line:

```bash
ewald examples                      # list the files and their installed folder
ewald examples --copy my_examples   # copy them into a writable folder
ewald-gui my_examples/POSCAR.SrTiO3
```

From Python:

```python
from ewald import examples, import_file

pipe = import_file(examples.path("Cu_void.lammpstrj"))
pipe = examples.load("Cu_md.extxyz")      # same as import_file on the example
examples.copy("my_examples")
```

## Scripts in this folder

- `notebooks/`: the notebooks of the manual's tutorials (docs/user/tutorials/), built on the example
  files above. Open them in the GUI (File › Open) or run them with `python`; `tests/test_tutorials.py`
  runs them.
  - `cu_void.py`: surface atoms of a void by coordination, styled and plotted (tutorial 1).
  - `srtio3_octahedra.py`: space group, TiO6 octahedra, bond lengths and a figure (tutorial 2).
  - `cu_md_trajectory.py`: displacements, MSD and force arrows over an MD run (tutorial 3).
- `demo.py`: renders sample trajectories and figures into `demo_out/`.
- `papers/`: reruns analyses from published papers on their own data, downloaded on first use
  with `examples.fetch` (see `docs/user/papers.md`; `ewald examples --papers` lists the data).
  Each writes a figure into `papers_out/` (or the folder given as argument) and prints the
  comparison with the paper:
  - `li6ps5cl_diffusion.py`: Li MSD and D* in the Li6PS5Cl argyrodite (AIMD), against kinisi.
  - `llzo_arrhenius.py`: Arrhenius activation energy of Li in LLZO from MD at 500-800 K.
  - `carbon_coordination.py`: amorphous carbon local energy by sp/sp2/sp3 and sp3 fraction vs density.
  - `asi_paracrystalline.py`: S(q), g(r) and diamond-like fraction of 100,000-atom amorphous Si.
  - `argyrodite_disorder.py`: Li MSD in Li6PS5I/Li6PS5Cl against anion site disorder (37 XDATCARs).
  - `tiof2_octahedra.py`: TiOF2 bond-length table, TiO(6-n)Fn octahedra and partial RDFs (POSCAR, CIF).
  - `ammonia_borane_fes.py` (needs the ewald-plumed plugin): PLUMED-NEST metadynamics FES from 4 walkers against `plumed sum_hills`.
  - `alanine_dipeptide_fes.py` (needs the ewald-plumed plugin): PLUMED-NEST alanine dipeptide phi/psi free energy surface.
  - `nbo2f_anion_order.py`: 92 VASP relaxations of NbO2F anion orderings as one series (`load_runs`, `check_run`), the chiral P3_121 ground state.
  - `fe_vacancy_neb.py`: VASP NEB folder of a vacancy hop in fcc Fe, energy profile and the 325 meV barrier.
  - `mgb2_phonons.py` (needs the ewald-phonopy plugin): MgB2 band structure from VASP forces and the E2g mode animated.
- `plugins/`: example reader, modifier, visual-element and overlay plugins (see the plugin guide in
  `docs/plugins/`).
